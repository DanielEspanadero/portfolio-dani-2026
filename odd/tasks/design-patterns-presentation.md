# Design patterns presentation

## Objective
Create an extensive Spanish beginner-friendly interactive presentation at `/presentaciones/patrones-diseño/`, teaching all 23 GoF patterns and a clearly separate modern Java/Spring complement through concept/code pairs.

## Scope and constraints
- Reuse the shared document shell and player; do not alter existing decks or unrelated pending portfolio changes.
- Start with objects, interfaces, composition, and reading Java; no prior design-pattern knowledge assumed.
- Every GoF pattern: problem, plain-language analogy, solution/roles, appropriate use, tradeoff/when not to use, minimal real Java with usage/result and explanation.
- Modern complement: Dependency Injection, Repository, DTO/mapping, Service Layer, Specification, Circuit Breaker/Retry (distinguish GoF, architecture and resilience; no new dependencies).
- Preserve public URL with ñ; ASCII internal directories allowed. Spanish content follows existing project convention.
- No build or unrelated cleanup. Feature branch derived from dev: `feat/design-patterns-presentation`. The latest user request (L40) authorizes scoped commits and controlled integration into `dev`, then `main` for deployment, only after successful review.
- Layout must be legible, responsive and printable; no clipped code. Honor no-JS and reduced-motion reading.

## Acceptance and verification
- Complete 5/7/11 GoF categories; each pattern has concept/code pair; modern topics explicitly labeled non-GoF.
- Exactly one h1; sequential named slides, complete metadata and canonical, navigation and discoverable index card.
- Node content/renderer tests, existing Node regression suite; validate core Java snippets with available JDK 21 where feasible.
- Browser probe desktop/mobile using local Astro dev server, no build; verify layout and code readability separately.
- Deterministic structural tests test-first where applicable. Pedagogical prose has no meaningful failing unit test: editorial readback plus content checks instead. Do not claim TDD requires activation.
